# Homework 02 — Project Scaffold Practice

In this exercise, I practiced building a full project folder structure from scratch using `mkdir -p`, creating the following inside `homework/homework02/`: 
- `data/raw/`
- `data/processed/`
- `notebooks/`
- `src/`
- `docs/`
- `reports/`
- `model/`  

Since git does not track empty folders, I added an empty `.gitkeep` placeholder file to each directory so the structure would be visible and trackable once committed and pushed to GitHub. 

This will help me set up a clean, organized folder structure as a foundation before any actual data or code is added.
